## What each column means

| col | meaning |
|---|---|
| `seq` | monotonically increasing decision id |
| `ts` | epoch ms of the decision |
| `window` | `day` / `night` — the "hours humans sleep" posture |
| `trigger` | macro/news/move/risk/hedge/rebalance/hold |
| `llm` | `live` (OpenAI-compatible) / `qwen` / `stub` |
| `nav_micro` | net asset value in micro-USD (1e6 = $1) at decision time |
| `rationale` | the decision-maker's reasoning |
| `orders` | executed order legs (action, key, usd, px, pnl, fee) |
| `review_verdict` | two-model audit: `pass` / `reject` / empty = nothing to audit |
| `review_rationale` | the auditor's reasoning |

Decisions that proposed no orders (`hold`) carry no audit verdict because there was no
plan to criticize. Auditor rejection drops the LLM's discretionary legs only — the risk
harness's own de-risk orders always survive.
